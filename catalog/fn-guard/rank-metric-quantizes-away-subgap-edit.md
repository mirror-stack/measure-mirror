# rank-metric-quantizes-away-subgap-edit — 순위 지표가 간극 이하 편집을 양자화로 삼킴

> A rank-based metric reads exactly zero change when the induced profile edit is smaller than every inter-candidate distance gap — the null is quantization, not absence.

- **증상(시그니처)**: 처치–대조 분리가 **정확히 0.0000**(교란별 짝대조 전부 0·부트스트랩 CI [0,0]). 지표값 자체는 중간대(바닥/천장 아님). 같은 두 팔이 **다른 지표에서는 분리됨**.
- **기전**: 순위 기반 지표(정답 후보의 거리 순위)는 연속 거리를 이산 순위로 양자화한다. 조작이 만든 거리 변화가 후보 간 거리 간극(gap)보다 작으면 순위가 하나도 안 뒤집혀 지표 이동이 **구조적으로 정확히 0**이 된다. "효과 없음"과 "지표 분해능 미달"이 같은 값으로 보인다. 고차원일수록(총거리=Σ18k유전자, 편집=1유전자) 간극 대비 편집이 작아져 잘 발생.
- **실사례**: [가상세포] VCC 1단계 앵커(prereg `25e7e78e` → 철회 `93167779`). train-only 앵커의 타깃 녹다운(단일유전자·비율 0.049)이 discrimination_score_l1(L1 순위)에서 ANCHOR 0.5164 = NEUTRAL 0.5164, 분리 0.0000. 조작은 실재했음 — 녹다운 적용 50/50·팔간 프로파일 상이 50/50·**DES(overlap_at_N)는 팔간 38× 분리**(0.0038 vs 0.0001). K1 사전봉인 조건으로 귀속 KILL 처리·앵커는 널앵커로 강등.
- **탐지법**: ①분리가 소수점 4자리까지 정확히 0이면 "약한 효과"가 아니라 이 착시부터 의심 ②같은 팔 쌍을 **연속 지표**(거리 자체·MAE·DE 통계)로 재대조 — 연속 지표가 갈리면 순위 양자화 확정 ③사전등록에 "주지표 무이동 시 연속 보조지표로 분해능 판정" 게이트를 박아라.
- **오적용 주의**: 연속 지표까지 전부 0이면 진짜 무효과일 수 있다. 이 라벨은 **다른 채널에 분리 증거가 있을 때만** — "지표 탓"으로 진짜 null을 기각하지 말 것.
