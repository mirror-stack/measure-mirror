# declared-hash-never-computed — 봉인에 적은 프로토콜 해시를 계산한 적이 없다

> A protocol hash written into a seal from memory or as a placeholder — never actually computed — makes the seal's identity promise vacuous, while chain verification, prereg lint and `verify_all` all still report OK.

- **증상(시그니처)**: kill_condition에 프로토콜 SHA256이 여러 개 나열돼 있는데, 그 중 **일부만** 실제 `sha256sum` 출력에서 복사됐다. 전형적 발생 위치 = 봉인 직전에 새로 쓴 분석 스크립트(측정은 나중이라 "아직 안 돌렸으니 나중에 확인하자"가 되는 자리), 여러 해시를 한 문단에 적을 때 형식 맞추려고 채워 넣은 자리. 사후 징후: 원장의 해시로 `sha256sum -c`류 대조를 **아무도 한 적이 없다**. 체인 검증·린트·verify_all은 전부 ✅ 이므로 아무 경보도 안 뜬다.
- **기전**: 원장이 보증하는 것은 **"이 문자열이 그때 봉인됐다"**이지 **"이 문자열이 참이다"**가 아니다. 해시는 봉인문 안에서는 그냥 텍스트다 — 체인 해시는 봉인문 전체를 덮지만, 봉인문 *내용*이 파일시스템의 실제 파일과 대응하는지 검사하는 층은 없다. 그래서 틀린 해시는 무결성 검사를 하나도 건드리지 않고 통과하며, 정확히 그 순간부터 "봉인된 프로토콜이 실행된 프로토콜과 같다"는 약속이 **반증 불가능**해진다. 착시의 핵심은 여기다: 규율을 지킨 겉모습(해시가 박힌 봉인)이 규율의 실질(프로토콜 동일성 증명)보다 먼저 완성된다.
- **실사례**: (FM×CDE 무대 v3 후속, 2026-07-31) ②거리-전이 재도전을 봉인하며 분석 스크립트 `93_distance_pooled.py`의 해시를 `9e9ac0f1`로 적었다 — 계산한 적 없는 값이다. 실제 `sha256sum` = **`978b5a75`**. 같은 봉인문의 다른 해시들(게이트 `fdf1ba61`·거리 `868dce6e`)은 출력에서 복사한 것이라 맞았고, 프리레그 린트는 clean(㉗ OK), 체인도 정상이었다. 봉인 직후 습관적으로 `sha256sum`을 돌려보다 불일치를 자가적발. 적발 시점에 ② 측정은 **0건**(새 홈 게이트 결과 없음, 93_은 abort 경로만 실행)이라 바·통계량을 결과에 맞춘 여지가 없었으므로, 잘못된 봉인 `cfcd6bc0`을 **지우지 않고**(append-only) 새 claim_id로 재봉인 `dc70d1a7`(supersede 사유 명시)+행동원장 `1dbfc02d`에 경위 기록. 처방 = 해시는 반드시 `sha256sum` 출력에서 복사, 기억·자리표시자 금지.
- **탐지법**: 봉인 **직후** 기계 대조를 1줄 넣는다 — 봉인문에서 해시를 파싱해 현재 파일의 `sha256sum`과 비교(불일치면 즉시 재봉인). 값싼 대안: 봉인 전에 관련 파일 전부를 한 번의 `sha256sum` 호출로 출력하고 **그 출력 블록에서만** 복사한다(손으로 타이핑하는 해시 0개). 사후 감사에서는 원장의 모든 프로토콜 해시를 실제 파일과 일괄 대조하는 스크립트를 돌린다 — 통과 못 하는 봉인은 프로토콜 동일성 주장을 못 한다.
- **오적용 주의**: ①해시 불일치 = 결과 조작이 **아니다**. 파일을 정당하게 수정한 뒤 재봉인을 안 한 경우, 경로/버전 착오, 접두사 자릿수 차이도 같은 증상을 낸다 — 라벨을 붙이기 전에 "선언된 해시가 *어떤* 파일과도 대응하지 않는가"를 확인하라(계산한 적 없는 값이라야 이 항목이다). ②결과를 본 **뒤** 발견됐다면 처리가 다르다: 이번처럼 측정 0건이면 새 claim_id 재봉인이 깨끗하지만, 이미 측정이 끝난 뒤라면 재봉인은 결과에 맞춘 사후 수정과 구별 불가이므로 **amendment로만** 기록하고 원 판정을 그대로 집행해야 한다. ③반대로 "해시가 틀렸으니 그 아크 전부 무효"도 과잉적발이다 — 무효가 되는 것은 프로토콜 동일성 주장이고, 영향범위를 같이 적어야 한다.
