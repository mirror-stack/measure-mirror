## Why this map exists

Seal `5c78e503` (substrate-2 generalization KILL, 0.80) exposed that an
aggregate detection score cannot distinguish mechanism from substrate luck,
because it does not decompose into "planted defect ↔ the clause that caught
it" rows — `relabeled_dof` had passed 22/22 on FM×CDE only because the
shuffled arm happened not to beat the null there. The mutation-testing
literature (arXiv 2607.08028, via the yeoul lane memo of 2026-08-07) treats
exactly this correspondence as the basic unit of verifier coverage, and
treats the **equivalent mutant** — a planted fault that never changed
behavior — as a known trap to screen for, not a judgment call.

The unit here: run the UNMODIFIED auditor on each planted mutant AND its
recovered honest parent, diff the finding profiles, and type every expected
clause — see `build_map.py`'s docstring for the ATTRIBUTED / DOMINATED /
CONSTANT_SUSPECT / EQUIVALENT_SUSPECT / UNSAT taxonomy.
