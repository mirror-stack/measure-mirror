# 🔗 외부 감사 원장 연동 (External-Witness) — v0.1

*[English →](INTEROP.md)*

> **한 문장:** 경쟁하지 않고 맞물린다 — 외부 감사 원장(행동 통치 스택의 변조증거 체인,
> 다른 팀의 해시체인 로그)의 **머리(head)**를 우리 행동 원장에 봉인해, 두 체인이 서로의
> 시점과 불변성을 증언하게 한다.

이 규격은 **J3(증인)**의 시스템 경계 확장이다. `am witness`는 같은 형식의 *am* 원장
머리를 고정하지만, 이 규격은 우리가 운영하지 않고 스키마도 해석하지 않는 체인의 머리를
고정한다. 코드가 아니라 문서 형식이다: 어댑터 없음, 폴링 데몬 없음, 스키마 매핑 없음.

## 왜 머리만인가

- **O(1)·스키마 무지.** 상대 항목을 파싱하지 않는다 — 그쪽 로그의 *의미* 검증은 그쪽
  검증기의 일이다.
- **J3과 같은 기제.** 시점 `T`에 머리 `H`를 우리 체인에 봉인하면, 이후 그쪽 체인에서
  `H`가 사라지는 순간(롤백·rewrite) 두 확정 원장의 공식 불일치가 된다 — 어느 쪽도
  지울 수 없는 사건.
- **정직한 범위.** 우리가 증명하는 것은 *"시점 T에 그들의 머리가 H였다"는 우리 주장*뿐.
  그들의 항목이 참인지는 증명하지 않는다.

## 항목 형식 (am action entry 1건)

```
action:  "external-witness"
agent:   <운영자>
target:  "<system>:<instance>"          예: "agent-governance-toolkit:tenant-a"
payload:
  system:       외부 시스템 식별 슬러그
  format:       그쪽 체인 형식 라벨       예: "hash-chain-jsonl" | "merkle"
  instance:     테넌트/배포 식별자
  head:         { hash, algo, seq, ts }  그쪽 체인 머리 — 해시는 전문(전체 자릿수)
  obtained_via: 머리를 어떻게 읽었나 — API 경로, export 파일+그 파일의 sha256,
                또는 정확한 조회 명령
  prev_external_witness: 같은 target 에 대한 직전 external-witness 항목의 seal
                (그쪽 체인에 대한 우리 *관측*의 체인화)
```

규칙:

1. **`head.hash`는 전문.** 축약 해시는 미확인 해시다.
2. **`obtained_via` 없으면 항목도 없다.** 아무도 재유도할 수 없는 증언은 증거 없는
   선언 — measure-mirror #47이 재는 바로 그 병(아무것도 재검증할 수 없는 선언된 체크).
3. **주기 관측은 체인화한다.** `prev_external_witness`가 반복 고정을 타임라인으로
   만들어, rewrite 가능 구간을 두 고정 사이 간격으로 좁힌다.

## 검증 절차 (사람/스크립트 공통)

- **V1 — 우리 쪽:** `am verify` → Overall OK. (am ≤0.2.x는 FAIL이어도 exit 0 —
  판정 줄을 파싱할 것. action-mirror#3에서 수리.)
- **V2 — 항목 존재:** `am history --action external-witness --target <t>`.
- **V3 — 그쪽:** `obtained_via` 재실행. `seq` 위치에 `hash`가 여전히 존재 → 우리 고정
  시점 이후 그 접두 구간의 불변 확인. 부재 → 두 원장의 공식 불일치: 그쪽 rewrite거나
  우리 오기록 — 어느 쪽이든 더는 조용히 수선할 수 없는 사건.
- **V4 — 상호(선택):** 그쪽 감사 로그가 자유 이벤트를 받으면 우리 현재 머리 seal을
  그쪽에 기록. 상호 고정은 위조 비용을 체인 하나에서 **두 체인 동시**로 올린다.

## 실례 (예시일 뿐, API 계약 아님)

행동 통치 툴킷이 SHA-256 해시체인 감사 로그를 유지하고 파일 export를 지원한다면:
`obtained_via: "export 2026-08-14 audit.jsonl sha256=<전문 해시>; head = 마지막 줄 체인 해시"`.
이 고정은 그 export를 가진 누구든 재검증할 수 있다 — 우리 인프라 접근 불필요.

## 비목표

라이브 어댑터·폴링 데몬(수요 신호 전 제외 — 2026-08-14 봉인된 결정), 외부 항목 의미
검증, 외부 시스템에 우리 스키마 강제. 그쪽 통치층은 행동을 *집행*하고, 우리 측정층은
주장을 *증명*한다. 맞물림은 양방향 각 한 개의 봉인된 머리다.
